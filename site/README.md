# SittingTime landing page

This is the static bilingual landing page recovered from the Vercel deployment and brought into the repository for continued design work. It has no build dependencies.

Preview locally from the repository root:

```sh
python3 -m http.server 4173 --directory site
```

Then open `http://localhost:4173`.

The Vercel project can use `site` as its root directory after its Git repository is connected.
